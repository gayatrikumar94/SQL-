# SQL Problem Solving Portfolio

Welcome to my personal sandbox! This repository tracks my journey mastering SQL by solving complex data problems **entirely from scratch**. 

Instead of relying on templates or quick hacks, I build every query here using raw logic. My goal is to build highly optimized queries while treating every problem like a real-world business case.

## Tech Stack & Core Concepts
*   **Dialects Practiced:** PostgreSQL | MySQL | T-SQL (MS SQL Server)
*   **Advanced Techniques:** Multi-table Joins, Common Table Expressions (CTEs), Subqueries, Window Functions (`RANK`, `LEAD/LAG`, `ROW_NUMBER`), and Row/Column Pivots.
*   **Focus Areas:** Data aggregation, complex transformations, and query optimization.

## How This Repository Is Organized
I group my solutions by platform and then nest them by difficulty. Every single problem folder contains a `solution.sql` file (my raw query) and a dedicated `README.md` explaining my thought process.
